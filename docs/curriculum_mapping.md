# Curriculum mapping

Detailed alignment of each TideGuard EE lesson with selected national /
international curricula. Required by the Zayed Global High Schools category and
useful for GEEP / MIT Solve education jurors.

|--------|--------|---------|
| 01 marine-plastic | INb-IV-1 / INf-IV-3 | Recognise human impacts on ocean ecosystems |

| 03 microplastic | INb-V-3 | Understand transformation processes in pollution |
| 04 read-the-map | INf-IV-1 | Apply quantitative reasoning to environmental data |
| 05 good-report | Pa-V-2 | Practice citizen science methodology |
| 06 safety | Hd-IV-3 | Apply field safety procedures |
| 07 organize-cleanup | Td-V-2 | Plan a sustained collective action |
| 08 sort-waste | Mc-V-3 | Classify waste streams |
| 09 reduce-reuse | Tg-V-1 | Practice 5R sustainability behaviours |
| 10 lead-school | Pe-V-2 | Lead a peer-action initiative |
